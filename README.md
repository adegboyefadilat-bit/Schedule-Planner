# My To-Do List

A simple, single-file to-do list app built with HTML, CSS, and vanilla JavaScript.

## Run

Open `index.html` in any modern browser. No installation or build step is required.

Optional local server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Features

- Add tasks with the Add Task button or Enter key.
- Toggle tasks as done with the "Mark as Done" checkbox.
- Delete individual tasks.
- Live total and completed counters.
- Friendly empty state and responsive layout.

Tasks are kept in memory only and reset when the page is refreshed.
